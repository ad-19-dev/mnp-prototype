# MNP prototype：團隊版（提案）

以雙語版為基礎，加上「團隊」：訊息、模板、收件群組可以屬於個人或某個團隊，團隊的成員都看得到團隊擁有的內容。
規則寫在 `src/lib/teams.ts`，團隊管理在 `src/pages/teams/TeamsPage.tsx`。

| 決策 | 這一版的做法 |
|---|---|
| 團隊從哪來 | 使用者自己建立，管理員管理成員；一個人可以加入多個團隊 |
| 誰看得到 | 自己建立的訊息，加上所屬團隊的所有訊息、模板、群組 |
| 成員能做什麼 | 查看、複製、補發給沒收到的人 |
| 誰能修改 | 建立者與團隊管理員：編輯、取消排程、重試 |
| 既有的個人模板與群組 | 維持個人；在編輯頁用「歸屬」移到團隊 |
| 離開團隊 | 自己以團隊名義送出的訊息仍看得到（只能查看、複製）；團隊其他內容看不到 |

執行方式與雙語版相同：`npm install --legacy-peer-deps` 後 `npm run dev`。
