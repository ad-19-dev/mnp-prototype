# MNP prototype：團隊版（提案）

以雙語版為基礎，加上「團隊」：訊息、模板、收件群組可以屬於個人或某個團隊，團隊的成員都看得到團隊擁有的內容。
規則寫在 `src/lib/teams.ts`，建立團隊與成員管理在 `src/components/TeamPanels.tsx`。

| 決策 | 這一版的做法 |
|---|---|
| 導覽 | 側邊欄「訊息」分組底下是「我的訊息」和每個團隊的訊息列表；「＋」建立團隊 |
| 我的訊息 | 我發出的所有訊息（個人的和以團隊名義發的） |
| 團隊的訊息列表 | 團隊所有成員發的訊息；右上角「成員」管理成員、離開團隊 |
| 團隊成員 | 沒有管理員，像聊天群組：每個人都能加入、移除成員，也能自行離開；最後一人離開時團隊解散 |
| 成員能做什麼 | 團隊的訊息大家權限相同：查看、編輯、取消排程、重試、複製、補發 |
| 模板與收件群組 | 屬於建立者，可共享給多個團隊；這些團隊的成員都能使用和編輯 |
| 離開團隊 | 自己以團隊名義送出的訊息留在「我的訊息」（只能查看、複製）；團隊其他內容看不到 |

執行方式與雙語版相同：`npm install --legacy-peer-deps` 後 `npm run dev`。
